# Decision list template

Create this in step 3. Update it after every round. It is also the save file: a new chat can resume from the "Next" section.

```
# <Project>: decision list
Status: Agreed 0 · Open 0 · Parked 0
Phase: <step> · Next: <what happens next>

## Brief
How might we …?
- You said: …
- My guess (unconfirmed): …

## Don't want
- …

## Your call
- <item>: <choice>, because <reason>

## Direction
<chosen direction and its walk-through>

## Agreed
- D1 <decision>. Why: <one line>

## Open
- …

## Parked
- …

## Rejected
- <idea>. Why: <one line>

## Next
<the next round's questions, so a new chat can resume here>
```

Rules:

- Rejected ideas stay listed with their reason, so nobody brings them back by accident.
- A guess moves from "My guess" to "You said" only after the user confirms it.
- Decision numbers (D1, D2, …) never change. The design doc refers to them.
